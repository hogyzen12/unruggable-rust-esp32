# Historical ESP32 development crate

This directory preserves the older development source already present in the
public repository. It is not the recovered 2026 preorder baseline.

- Original ESP32 preorder boards: [frozen v0.1.0 source, binaries and instructions](../firmware/esp32-only/README.md).
- V2 boards with SE050 and Tropic: [dual-element firmware](../firmware/dual-element/README.md).

The older source and scripts remain here for development history. Follow the
family-specific instructions above when selecting firmware for a device.
